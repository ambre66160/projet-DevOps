# 🚀 Projet DevOps Lab — Initiation & CI/CD

Un projet de démonstration conçu pour apprendre et mettre en pratique les bases de la culture DevOps : conteneurisation, automatisation des tests et mise en place d'un pipeline CI/CD.

---

## 🛠️ Stack Technique

* **Langage / Application** : Python (Flask) / Node.js *(à adapter selon ton code)*
* **Conteneurisation** : Docker & Docker Compose
* **CI/CD** : GitHub Actions (ou GitLab CI)
* **Tests** : Pytest / Jest

---

## 📋 Prérequis

Avant de commencer, assure-toi d'avoir installé sur ta machine :

* [Git](https://git-scm.com/)
* [Docker Desktop](https://www.docker.com/products/docker-desktop/) (avec Docker Compose)
